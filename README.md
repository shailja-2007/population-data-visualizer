Population Data Visualizer

PS No.: 30
Project Title: Population Data Visualizer
Language: Python 3

1. Project Overview

This project analyzes city population data from a CSV file and displays population statistics and growth using charts.

2. Objectives

- Calculate total population.
- Find the largest city.
- Calculate city-wise population growth.
- Display population data graphically.

3. Features

- CSV data reading using Pandas.
- Invalid data handling.
- Population summary.
- Growth percentage calculation.
- Bar chart and line chart.

4. Requirements

- Python 3
- Pandas
- Matplotlib

Install libraries:

pip install pandas matplotlib

5. Project Files

- "one.py" – Main Python program.
- "population.csv" – Input dataset.
- "README.md" – Project documentation.
- "Test_cases_passed.pdf" – Testing screenshots.

6. Execution Instructions

1. Open the project folder in VS Code.
2. Install the required libraries.
3. Run:

python one.py

4. Select menu option 1 or 2.

7. Input Details

Input is provided through "population.csv" containing City, Year and Population columns.

8. Output Details

The program displays total population, largest city, fastest-growing city and two charts:

- Population Growth by City
- Population Trend

9. Testing

The project is tested using four test cases:

1. Normal Input
2. Boundary / Minimum Input
3. Invalid Input
4. Different Valid Scenario

10. Conclusion

The project successfully analyzes and visualizes city population data using Python, Pandas and Matplotlib.
